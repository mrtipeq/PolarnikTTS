PolarnikTTS

Voice-over for YouTube subtitles – settings

Language

"Automatic" follows your system language. The voice-over language decides what the subtitles are translated into and which voices are offered; changing it re-synthesizes the current video.

Engine server

The PolarnikTTS server can run on this computer or on another one in your local network (e.g. a machine with a GPU).

Voice

Engines and voices

Connect to the server to manage engines.

Translation

LLM translators restore punctuation and sentence boundaries – that is what gives the voice-over natural intonation. Enable them and enter API keys in "Engines and voices" above.

Playback

Moving settings

Export writes the extension settings, the server configuration (engines, translators, API keys) and voice samples into one file. On the other computer: install PolarnikTTS, start the server and import the file. The file contains API keys – treat it like a password.

About

PolarnikTTS

Voice-over for YouTube – translates the subtitles and reads them in real time with the engine of your choice: local (GPU/CPU) or cloud, with voice cloning from your own sample.

Author: MrTip (Darek) · Tipson · tipson.pl · GitHub · report a problem

Designed and built entirely under the command of Claude Fable 5.1 (High) by Anthropic – from the analysis of the original, through architecture and the server and extension code, to testing – to MrTip's idea and requirements.

MIT licence. Extension: Manifest V3, no libraries and no telemetry – nothing is sent anywhere except to the PolarnikTTS server and the providers you enable yourself. Server: Python + FastAPI, engine plugins (Microsoft Edge, Piper, Chatterbox, XTTS-v2, OpenAI, Gemini, ElevenLabs) and translators (OpenAI, Gemini, Ollama/Bielik, Claude, DeepL).
